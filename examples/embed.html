Embed Examples

Different ways to embed Premium FlipBook in your website

Full Width Embed

A full-width flipbook that takes the entire container width.

<div id="flipbook" style="width: 100%; height: 500px;"></div> <script type="module"> import PremiumFlipBook from 'premium-flipbook'; new PremiumFlipBook({ container: '#flipbook', images: ['page1.jpg', 'page2.jpg', 'page3.jpg'], renderMode: 'css' }); </script>

Multiple Instances

You can have multiple flipbooks on the same page.

Magazine A

Travel Photography Collection

Magazine B

Architecture Portfolio

// Multiple instances on same page const flipbook1 = new PremiumFlipBook({ container: '#flipbook-a', images: travelImages }); const flipbook2 = new PremiumFlipBook({ container: '#flipbook-b', images: architectureImages });

Responsive Design

The flipbook automatically adapts to container size and switches to single-page mode on mobile.

new PremiumFlipBook({ container: '#flipbook', images: myImages, // Responsive settings singlePageMode: 'auto', // auto, always, never singlePageBreakpoint: 768, // Switch to single page below this width // Container adapts to size width: '100%', height: 'auto', aspectRatio: 1.414 // A4 ratio });

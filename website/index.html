Simple Integration

Get started in minutes with our clean, intuitive API. Works with any framework or vanilla JavaScript.

  • ES Modules & UMD builds
  • NPM package available
  • TypeScript definitions included
  • Comprehensive documentation
  • MIT License - Free forever
import PremiumFlipBook from 'premium-flipbook';

// Initialize with PDF
const flipbook = new PremiumFlipBook({
  container: '#flipbook',
  pdfUrl: './magazine.pdf',
  renderMode: 'auto',

  ui: {
    toolbar: { enabled: true },
    thumbnails: { enabled: true }
  },

  onReady: (fb) => {
    console.log('Ready!', fb.getPageCount());
  }
});

// Navigate programmatically
flipbook.nextPage();
flipbook.goToPage(5);
flipbook.setTransition('flip');

RTL Support - دعم اللغات من اليمين إلى اليسار

Right-to-left reading direction for Arabic, Hebrew, and Persian

RTL Mode Features

In RTL mode, the flipbook mirrors the page order and navigation direction to match right-to-left reading patterns.

✓ Pages displayed right-to-left ✓ Mirrored navigation ✓ Keyboard arrows reversed ✓ Swipe direction reversed

Code Example

const flipbook = new PremiumFlipBook({
  container: '#flipbook-container',
  pdfUrl: './document.pdf',

  // Enable RTL mode
  rtl: true,

  // Optional: Custom localization
  i18n: {
    locale: 'ar',
    strings: {
      firstPage: 'الصفحة الأولى',
      previousPage: 'الصفحة السابقة',
      nextPage: 'الصفحة التالية',
      lastPage: 'الصفحة الأخيرة',
      zoomIn: 'تكبير',
      zoomOut: 'تصغير',
      fullscreen: 'ملء الشاشة',
      thumbnails: 'المصغرات',
      search: 'بحث',
      pageOf: 'من',
      loading: 'جار التحميل...'
    }
  }
});

// RTL mode automatically:
// - Reverses page display order
// - Mirrors navigation controls
// - Inverts keyboard arrow keys
// - Reverses swipe gesture direction

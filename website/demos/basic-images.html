Image Array Source

Display a flipbook from an array of images - no dependencies required

Code Example

import PremiumFlipBook from 'premium-flipbook-pdf-viewer';

// Define image URLs
const images = [
  'pages/page-01.jpg',
  'pages/page-02.jpg',
  'pages/page-03.jpg',
  'pages/page-04.jpg',
  'pages/page-05.jpg'
];

// Initialize flipbook with image array
const flipbook = new PremiumFlipBook({
  container: '#flipbook-container',

  // Image source - array of URLs
  images: images,

  // CSS renderer works without Three.js
  renderMode: 'css',

  // Page dimensions (optional)
  pageWidth: 800,
  pageHeight: 1131,

  // UI configuration
  ui: {
    toolbar: { enabled: true },
    thumbnails: { enabled: true }
  },

  onReady: (fb) => {
    console.log('FlipBook ready with', fb.getPageCount(), 'images');
  }
});
Note: When using images as source, no PDF.js dependency is needed. The CSS renderer also works without Three.js, making this the lightest configuration.

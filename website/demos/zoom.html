Zoom & Pan

Interactive zoom controls with multiple input methods

100%

Ctrl + Scroll to zoom | Pinch to zoom on touch | Double-tap to zoom | Drag to pan when zoomed

Code Example

const flipbook = new PremiumFlipBook({
  container: '#flipbook-container',
  pdfUrl: './document.pdf',

  // Zoom configuration
  zoom: {
    enabled: true,
    min: 1,              // Minimum zoom (100%)
    max: 4,              // Maximum zoom (400%)
    step: 0.25,          // Zoom increment
    doubleTapZoom: 2,    // Double-tap zoom level
    wheelZoom: true,      // Enable Ctrl+scroll
    pinchZoom: true,      // Enable pinch-to-zoom
    panEnabled: true      // Enable drag-to-pan
  }
});

// Zoom API
flipbook.setZoom(2);      // Set to 200%
flipbook.zoomIn();        // Zoom in by step
flipbook.zoomOut();       // Zoom out by step
flipbook.resetZoom();     // Reset to 100%
flipbook.getZoom();       // Get current zoom level

// Listen to zoom changes
flipbook.on('zoomChange', ({ zoom, previousZoom }) => {
  console.log(`Zoom changed: ${previousZoom} → ${zoom}`);
});

Mouse Wheel

Hold Ctrl and scroll to zoom in/out on desktop browsers.

Pinch Zoom

Use two-finger pinch gesture on touch screens.

Double Tap

Double-tap on mobile to quickly zoom to 200%.

Pan & Drag

When zoomed, drag to pan around the page.

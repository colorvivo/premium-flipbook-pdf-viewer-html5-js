Page Transitions

Compare different page transition effects

Code Example

// Set transition type dynamically
flipbook.setTransition('fade');   // Smooth fade between pages
flipbook.setTransition('slide');  // Slide with 3D perspective
flipbook.setTransition('flip');   // 3D page flip rotation
flipbook.setTransition('none');   // Instant page change

// Get current transition type
const current = flipbook.getTransition();

// Transition works with all renderers
// (WebGL, CSS, and Swipe)

Fade

Smooth opacity transition. Works well for all content types.

Slide

3D slide with perspective and scaling. Creates depth effect.

Flip

Classic 3D page flip rotation. Book-like experience.

None

Instant page change. Best for quick navigation.
